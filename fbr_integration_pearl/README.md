## 🔹 Overview
The **FBR Integration Enhanced** module connects your Odoo accounting system with **FBR’s real-time invoice reporting system**, enabling compliance with tax regulations in Pakistan.  
It comes with enhanced dropdown field support for flexible invoice handling.

---

## 🚀 Key Features
- Real-time **invoice reporting** to FBR
- Dropdown fields for **simplified selection**
- Secure **API integration**
- Detailed **FBR Sync Logs**
- Customizable **invoice reports**
- Seamless integration with **Odoo Accounting & Invoicing**

---

## 📦 Dependencies
- Odoo **Base**
- Odoo **Accounting**
- Odoo **Product**

---

## 📑 Included
- Security access controls
- Settings view for FBR API
- Invoice & move views
- Sync logs view
- Invoice report templates
- Sample data file

---

## 🔧 Installation
1. Upload the module into your Odoo **addons** folder.
2. Update the App list (`Apps > Update Apps List`).
3. Install **FBR Integration Enhanced**.
4. Configure FBR API credentials in **Settings > FBR Integration**.

---

## 📊 Usage
- Create or validate an invoice in Odoo.  
- System automatically sends details to **FBR**.  
- View logs in **FBR Sync Logs** menu.  
- Dropdown fields simplify tax type & POS selection.
